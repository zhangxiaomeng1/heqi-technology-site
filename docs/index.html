01 / 关于赫启

让复杂的工厂问题，
有一支工程团队负责。

唐山赫启科技有限公司位于唐山市高新区机器人特色产业基地，是一家以高新技术为主导的现代化民营企业。

公司以工厂自动化整体解决方案为主项，围绕工业机器人集成应用、机械设备控制、自动化上位系统、环保再生设备等技术开展工程设计与技术支持。
